- קובץ אחד, `index.html`. נפתח ישירות בדפדפן, בלי שרת, בלי הרשמה ובלי קריאות AI.
- עברית, מימין לשמאל, מותאם לנייד ולמצב כהה.
- התרחיש, החברה והנתונים בדויים.
