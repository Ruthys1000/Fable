# תיק פתוח

סימולציית חקירה למנהלי למידה ויועצים ארגוניים: ארגון כבר החליט שצריך קורס, ולמשתתף יש יום עבודה אחד לברר מה הבעיה האמיתית.

- קובץ אחד, `index.html`. נפתח ישירות בדפדפן, בלי שרת, בלי הרשמה ובלי קריאות AI.
- עברית, מימין לשמאל, מותאם לנייד ולמצב כהה.
- התרחיש, החברה והנתונים בדויים.

# מה נכון לייצר

מצגת־משחק לסשן כנס של 15 דקות: `ma-nachon-leyatzer.html`. קובץ יחיד, עובד בלי רשת (פונט Assistant ואייקוני Lucide מוטמעים בתוכו).

- מקשים: `←` או רווח לצעד הבא, `→` אחורה, `H` לרשימת המקשים המלאה.
- `P` פותח חלון מנחה עם הערות, שעון והצעד הבא. `N` מציג הערות בתחתית המסך.
- `S` פותח מסך ניהול (קוד 1234) לחיבור OpenAI. בלי מפתח, או כשקריאה נכשלת, המסך מציג תשובות דמו.
